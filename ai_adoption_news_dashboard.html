Current dashboard scope

Official AI communication in annual filings

This dashboard treats 10-K reports as official corporate communication texts. It analyzes how Fortune 2025 Top 100 firms communicate AI through disclosure intensity, framing, specificity, communication mode, and application domains.

Data boundary

Repository-contained evidence only

The current dashboard uses only the CSV files already present in the repository and does not present external outcome analyses as current results.

7. Measurement Design

From filing text to firm-year communication measures

1. Collect 10-K TextUse observed filing text already present in the repository sample.
2. Extract AI Sentences / WindowsIdentify AI-related text units for measurement.
3. Classify AI FramesAssign opportunity, risk, governance, infrastructure, and application themes.
4. Score Specificity and ModeDistinguish generic mentions from substantive disclosure and coding posture.
5. Aggregate to Firm-YearConvert extracted windows into firm-year communication measures.
6. Compare by ConditionsDescribe variation by report year, firm visibility, text coverage, and validated sector groupings.
Opportunity

Strategic Opportunity

AI as growth, innovation, productivity, efficiency, or competitive advantage.

Risk and Governance

Control and Accountability

AI as legal, regulatory, cybersecurity, operational, ethical, or governance exposure.

Application

Infrastructure and Use

AI as investment in data, cloud, models, platforms, customer systems, or business processes.

8. Limitations and Future Extensions

Current boundaries and later analysis paths

Current Limitations

External responses are not measured in the current repository.
Stock price data are not yet collected or joined.
Media response, analyst response, SNS response, Google Trends, and market response data are outside the current dashboard scope.
Sector categories are approximate and derived from downstream enrichment, not fully verified firm-level classifications.
The current dashboard is descriptive and measurement-oriented.
Topic-model outputs are descriptive, not causal estimates.
Workflow hardening remains a later engineering task.

Future Extensions

Refine SIC/NAICS or manually coded industry groups.
Add validated industry-level descriptive comparisons.
Validate frame classification through dictionary, topic model, and manual audit.
Collect stock-price data for publicly traded firms.
Build post-filing market outcome measures only after stock data are collected and audited.
Potential future outcomes: monthly return, abnormal return, volatility, trading volume.
Extend to media, analyst, or SNS response only if reliable data become available.
Standalone responsive HTML dashboard. No external libraries required.
